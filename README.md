# Парсинг новостей Ведомостей

Учебный HTTP-сервис на Node.js, Express и EJS.

## Запуск

Требуется Node.js 22 или новее и подключение к интернету.

```sh
npm ci
npm start
```

Откройте http://localhost:3000. Остановка сервера: Ctrl+C.

## Использование

Маршрут: `/:count/news/for/:category`.

Пример: http://localhost:3000/10/news/for/politics.

`count` — целое положительное число. Допустимые категории: `business`, `economic`, `finances`, `politics`.

На главной странице можно выбрать количество и категорию. При смене категории или нажатии кнопки отправляется запрос на сервер. При загрузке страницы фронтенд запрашивает `/api/categories`; сервер получает HTML https://www.vedomosti.ru/info/rss, извлекает ссылки четырёх допустимых категорий и возвращает список.

Сервер отправляет GET-запрос к https://api.rss2json.com/v1/api.json с параметром `rss_url`, получает JSON, выбирает новости и формирует HTML через EJS. Результат содержит заголовки и описания в списке `<dl>`. Ошибочные параметры, неизвестные маршруты, сбои источника и таймауты обрабатываются отдельной страницей ошибки.

Параметры задания `economic` и `finances` сопоставляются с RSS `economics` и `finance`. Ссылки `.xml` нормализуются без суффикса для совместимости с rss2json. Если сайт категорий недоступен, используется резервный список с уведомлением.

## Необязательные настройки

Без API-ключа rss2json обычно отдаёт до 10 записей. Если доступно меньше запрошенного количества, приложение показывает все полученные записи и предупреждение. Для передачи параметра `count` в rss2json скопируйте `.env.example` в `.env` и заполните `RSS2JSON_API_KEY` собственным ключом. Количество также зависит от RSS и ограничений сервиса. Документация: https://rss2json.com/docs.

`PORT` в `.env` позволяет изменить порт. Файл `.env` и папка `node_modules` исключены из Git.

## Структура

```text
server.js          Express, маршруты, EJS, запуск сервера
src/services.js    категории и запросы rss2json
public/client.js   форма и динамический список
public/style.css   оформление
views/             EJS-шаблоны
package.json       зависимости и команды
package-lock.json  точные версии зависимостей
.env.example       пример настроек
.gitignore         исключения для Git
```

Источник новостей — Ведомости. Публикации содержат ссылки на оригиналы.
